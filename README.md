# Mavis’s Costume Chaos

Self-contained Atelier 35 release adapted for Genially. All artwork is embedded. The outer page scales the scene uniformly and expands its logical canvas to fill the available iframe without dark margins, stretching or cropped controls. No external libraries or asset hosting required.

Published URL: https://natalifilonovets.github.io/show/

Paste `genially-embed.html` into Genially’s external-content iframe field. The scene fills the available frame at any aspect ratio; the entire interface stays visible. Enable autoplay/fullscreen permissions. Browser policy may still require a click for Mavis’s voice. Mouse/touch puzzle dragging runs inside the scaled frame.

GitHub Pages source: **GitHub Actions**. `.github/workflows/pages.yml` deploys on pushes to `main`.

`game.html` contains the complete game; `index.html` is the scaling wrapper. Update the game by rebuilding with `tools/build-genially.py` from the source project and copying the resulting files here.
